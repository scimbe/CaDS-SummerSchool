# Tutorials

Drei Durchgänge, aufeinander aufbauend. Jeder endet mit etwas, das läuft.

Sie sind zum Mitmachen gedacht, nicht zum Überfliegen: Es gibt genau einen Weg,
und der funktioniert. Abweichungen und Varianten stehen in den
[How-to-Anleitungen](../how-to/index.md), die Begründungen in
[Erklärung](../explanation/index.md).

1. **[Die erste Anfrage](erste-anfrage.md)** — vom `curl` zum Tool-Calling.
   Rund 20 Minuten.
2. **[Der erste Bericht](erster-bericht.md)** — offene Daten, ein Harness, ein PDF.
   Rund 30 Minuten.
3. **[Die erste Oberfläche](erste-oberflaeche.md)** — ein Prompt steuert die API.
   Rund 30 Minuten.

Vorher einmalig: [Endpunkt einrichten](../how-to/endpunkt-einrichten.md).
